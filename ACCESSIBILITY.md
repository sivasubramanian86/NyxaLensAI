# Accessibility

NyxaLensAI aims to make its developer interface usable with keyboard navigation,
screen readers, browser zoom, and reduced-motion preferences. The target is WCAG
2.2 AA, but no independent accessibility audit or conformance claim has been
completed.

The interface includes scan forms, status polling, score and traffic-light
indicators, diagrams, and dossier content. Important status must not rely on
color alone; SVG and Mermaid views should have a readable text fallback.

To report a barrier, use a private issue in the repository and include the page,
browser and assistive technology (if applicable), steps to reproduce, and the
impact. Do not include personal or customer data.
